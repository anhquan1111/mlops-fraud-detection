## 1. BẢN CHẤT: TẠI SAO CẦN ĐẨY MODEL LÊN HUGGING FACE?

1. **Nguyên tắc Git:** Các tệp model nhị phân nặng (`.pkl`) bị đưa vào `.gitignore` để tránh làm phình to kho mã nguồn GitHub.
2. **Nhu cầu của Render:** Khi container của Render khởi động, nó cần một nơi lưu trữ đám mây để tải file trọng số model vào RAM.
3. **Vai trò của Hugging Face Hub:** Đóng vai trò là **Kho lưu trữ Model Artifact tĩnh** miễn phí, bảo mật và tốc độ cao.

## 2. BƯỚC 1: LẤY ACCESS TOKEN TRÊN HUGGING FACE

Để cho phép script từ máy tính của bạn tự động tạo repo và tải file lên Hugging Face, bạn cần một **Personal Access Token có quyền Write**:

1. Đăng nhập vào tài khoản: [huggingface.co](https://huggingface.co).
2. Bấm vào Avatar góc trên cùng bên phải -> Chọn **Settings**.
3. Tại menu bên trái, chọn mục **Access Tokens** (hoặc truy cập thẳng: `https://huggingface.co/settings/tokens`).
4. Bấm nút **Create new token**:
   - **Token type:** Chọn **Write** (bắt buộc quyền Write để được phép tải file lên).
   - **Token name:** Đặt tên gợi nhớ (ví dụ: `fraud-export-token`).
5. Bấm **Create token** -> Copy chuỗi token (dạng `hf_xxxxxxxxxxxxxxxxxxxx`).

![Giao diện Access Tokens trên Hugging Face](images/hf_token_setup.png)

### 2.1. Phân biệt 2 loại Token: Token tạo tay trên Web vs. Token tự động qua `login()`

Rất nhiều kỹ sư thắc mắc: *"Tại sao chuỗi token lưu trên máy khác với chuỗi tạo trên web?"*

Hugging Face có 2 cơ chế cấp quyền:

1. **User Access Token (Tạo thủ công trên Web `settings/tokens`):**
   - Định dạng: Chuỗi ngắn, bắt đầu bằng `hf_...`.
   - Mục đích sử dụng: Dành cho **Server Cloud (như Render, GitHub Actions)** – những nơi máy chủ không có chuột hay màn hình để bạn bấm xác thực. Bạn sẽ copy chuỗi này dán vào bảng biến môi trường (`Environment`).
2. **OAuth Access Token (Tự động sinh khi chạy `login()` qua trình duyệt):**
   - Định dạng: Chuỗi mã hóa JWT dài 825 ký tự, bắt đầu bằng `hf_oauth_...`.
   - Cách tạo: Bạn chỉ cần chạy lệnh:
     ```powershell
     uv run python -c "from huggingface_hub import login; login()"
     ```
     Trình duyệt bật lên, bạn bấm **Authorize**, Hugging Face sẽ **tự động sinh ra token này và lưu thẳng vào tệp `C:\Users\Admin\.cache\huggingface\token`** trên máy bạn.
   - Mục đích sử dụng: Dành cho **máy tính cá nhân của Developer**, giúp máy tự động nhớ tài khoản vĩnh viễn mà không cần phải gõ lại hay copy token vào terminal nữa!

## 3. BƯỚC 2: ĐOẠN CODE NÀO TRONG DỰ ÁN THỰC HIỆN VIỆC NÀY?

Toàn bộ logic xuất model và tải lên Hugging Face nằm tập trung tại:  
👉 **[scripts/export_model.py](file:///D:/Documents/Project/mlops-fraud-detection/scripts/export_model.py)**

Trong tệp này có 3 khối code then chốt:

### Khối 1: Trích xuất Model tốt nhất từ MLflow Registry
```python
# scripts/export_model.py (Dòng 95 - 135)
def export_model(upload: bool = False):
    # 1. Tìm model mang alias 'production' trong MLflow
    model_version = client.get_model_version_by_alias("fraud-detection-model", "production")
    
    # 2. Tải model về và lưu ra file pickle cục bộ
    model = _load_any_flavor(model_version.source)
    joblib.dump(model, LOCAL_MODEL_PATH)  # Lưu ra models/baseline_lr.pkl
```

### Khối 2: Tự động tạo Model Card (README.md) từ Metric thật
```python
# scripts/export_model.py (Dòng 190 - 240)
# Đọc các chỉ số PR-AUC, Recall, Precision từ MLflow run tương ứng
metrics = _load_run_metrics(model_version.run_id)

card_content = f"""---
language: en
tags:
  - fraud-detection
  - lightgbm
---
# Credit Card Fraud Detection — Champion Model
## Performance
| Metric | Value |
|--------|-------|
| PR-AUC | {metrics.get('val_pr_auc'):.4f} |
| Recall | {metrics.get('val_recall'):.4f} |
"""
```

### Khối 3: Gọi API của Hugging Face để tải 2 tệp lên
```python
# scripts/export_model.py (Dòng 161 - 270)
from huggingface_hub import HfApi

api = HfApi(token=hf_token)

# 1. Tự tạo repository nếu chưa tồn tại
api.create_repo(repo_id=hf_repo_id, repo_type="model", exist_ok=True, private=False)

# 2. Tải file trọng số pickle lên
api.upload_file(
    path_or_fileobj=str(model_path),
    path_in_repo=MODEL_ARTIFACT_FILENAME,
    repo_id=hf_repo_id,
    repo_type="model",
)

# 3. Tải file README.md (Model Card) lên
api.upload_file(
    path_or_fileobj=card_content.encode("utf-8"),
    path_in_repo="README.md",
    repo_id=hf_repo_id,
    repo_type="model",
)
```

## 4. BƯỚC 3: CÂU LỆNH CHẠY THỰC TẾ TRÊN TERMINAL

Mở terminal PowerShell tại thư mục gốc của dự án `mlops-fraud-detection` và chạy lần lượt các lệnh:

```powershell
# 1. Gán token của bạn
$env:HF_TOKEN = "hf_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

# 2. Gán tên repo bạn muốn tạo trên Hugging Face
$env:HF_REPO_ID = "votrananhquan/fraud-detection-model"

# 3. Đảm bảo mã hóa UTF-8 cho Windows console
$env:PYTHONIOENCODING = "utf-8"

# 4. Chạy lệnh xuất và upload
uv run python scripts/export_model.py --upload
```
