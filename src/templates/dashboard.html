📦 Data Ingestion & Imbalance Assessment

Loaded 284,807 credit card transactions. Identified extreme class imbalance: 492 fraud vs 284,315 legit (~0.173% positive rate).

data/raw/creditcard.csv Imbalance: 1:577 Pydantic Validation
2

⚙️ Feature Engineering & Leakage-Free Split

Scaled transaction Amount using StandardScaler. Dropped non-predictive Time column. Stratified 80/20 train/test split to preserve fraud ratio strictly.

src/features.py StratifiedSplit (seed=42) No Data Leakage
3

🧪 MLflow Experiment Grid (7 Runs Logged)

Trained Logistic Regression baseline, 3 XGBoost configurations (scale_pos_weight), and 3 LightGBM configurations (class_weight='balanced'). Tracked all artifacts, metrics, and PR curves.

src/train.py MLflow 3.x SQLite PR-AUC Optimization
4

🛡️ Automated Validation Gate & Promotion

Validation Gate enforces business rules: Recall ≥ 0.80, Precision ≥ 0.50, and PR-AUC ≥ current production model. Champion model promoted to MLflow Model Registry alias production.

src/validate.py Recall ≥ 80% Champion: lgbm_large (PR-AUC 0.8770)

Packaged FastAPI serving with Docker (libgomp1 OpenMP, uv package manager). Automated CI with 61 pytest tests. Model weights downloaded dynamically from Hugging Face Hub.
